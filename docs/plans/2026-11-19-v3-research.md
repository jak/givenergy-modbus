## A. Model detection

HR 0 is the device type code (4 hex digits), HR 21 the ARM firmware.

| HR 0 | Model | Notes |
|---|---|---|
| `20xx` | ARM ÷ 100: 3 → `hybrid_gen3`; 8, 9 → `hybrid_gen2`; else → `hybrid_gen1` | Gen1 firmware lines 1xx, 2xx, 4xx |
| `21xx` | `polar` | |
| `22xx` | `hybrid_gen3_plus` | Library falls back to coarse "hybrid" |
| `23xx` | `pv` (PV-only, no battery) | GivTCP uses a separate PV read path |
| `24xx`, `25xx` | Unknown hybrid (ALPS-CUBE, POL-HY) | Treat as `hybrid_gen3` layout, no extras |
| `3xxx` | `ac` | |
| `40xx` | `hybrid_3ph` | HR 21 reads 0; firmware is IR 1325–1327 |
| `41xx` | `all_in_one_commercial` (three-phase) | |
| `5xxx`, `51xx` | `ems` | Refused |
| `6xxx` | `ac_3ph` | |
| `7xxx` | `gateway` | Refused |
| `80xx` | `all_in_one` | |
| `81xx` | `hybrid_hv_gen3` | Single-phase, HV battery. Answers IR 1000–1413 with zeros |
| `82xx` | `all_in_one_hybrid` | Library says three-phase; GivTCP forces single-phase (giv_tcp#621) |
| `83xx` | `hybrid_gen4` | |

The current library's `device-types.ts` / `generation.ts` collapse most of these into
`gen2`/`gen3`.

Rated power per DTC: 63 codes in the external library's `_DTC_RATED_POWER`. Battery max power:
`20xx` is 3600 W if firmware century is 3, 8 or 9, else 2600 W; others from `_DTC_BATPOWER`;
unknown → undefined. LV battery rate is capped at 50% of capacity.

## B. Capabilities per model

| Capability | Models |
|---|---|
| `tenSlots` (HR 240–299, charge slot 2 at HR 243/244) | `hybrid_gen4`, `all_in_one`, `all_in_one_hybrid`, `hybrid_hv_gen3`, `hybrid_gen3` with ARM > 302, three-phase (slots 3–10 + targets) |
| `perSlotTargets` | `tenSlots` single-phase models, `hybrid_3ph`, `ac_3ph` |
| `pauseMode` (HR 318) | `all_in_one`, `hybrid_gen2`, `hybrid_gen3`, `hybrid_hv_gen3`, `all_in_one_hybrid`; `ac` ARM ≥ 200; `hybrid_gen1` ARM ≥ 187 |
| `pauseWindow` (HR 319/320) | as `pauseMode` except `ac` and `hybrid_gen1` (Gen1 rejects any read or write touching 319/320) |
| `acSettingsBlock` (HR 300–359: 311, 313, 314, 317) | `ac`, `all_in_one`; HR 313/314 also `hybrid_gen1`, `hybrid_gen3`, `all_in_one_hybrid`. **The reference Gen3 (ARM 316) answers all of HR 300–359**, although the library says DC hybrids time out there; treat it as supported on `hybrid_gen3` and handle a timeout as "unsupported" |
| `smartLoad` (HR 540–573) | None confirmed. Times out on Gen1 ARM 449, Gen2 ARM 920 and the reference Gen3 |

Writes on single-phase (library `manifest.py:348`): HR 20, 27, 29, 31/32 (not on 10-slot
models: they return an error, #619), 35–40, 44/45, 50, 56/57, 59, 94/95, 96, 110, 111, 112,
114, 116, 163, 166; slot 3–10 times; slot targets when `perSlotTargets`; 311/313/314/317 when
`acSettingsBlock`; 318–320 per pause rules.

Three-phase uses different registers:

| Setting | Single-phase | Three-phase |
|---|---|---|
| Charge slot 1 / 2 | 94/95, 243/244 (or 31/32) | 1113/1114, 1115/1116 |
| Discharge slot 1 / 2 | 56/57, 44/45 | 1118/1119, 1120/1121 |
| Enable charge schedule | 96 | 1112 (AC charge) + 1123 (force charge) |
| Enable discharge schedule | 59 | 1122 |
| Battery reserve | 110 | 1109 |
| Charge target SOC | 116 | 1111 |
| Battery cutoff | 114 | 1078 |
| Charge / discharge power % | 313 / 314 | 1110 / 1108 |
| Export limit | HR 26 (read only) | 1102 when 1103 enabled |
| Real-time control | 166 | 166 (1005 also exists) |

No pause controls on three-phase. Slots 3–10 and their targets use the same HR 246–299 as
single-phase.

Polled blocks: IR 0/180 and HR 0/60/120 everywhere; HR 240 when `tenSlots`; HR 300 when
`acSettingsBlock`; three-phase adds HR 1000/1060/1120(5) and IR 1000–1413. HR 180 is not needed.

## C. Register meanings (corrections and additions)

Single-phase holding:

| HR | Meaning |
|---|---|
| 20 | Enable charge target (doc `WinterModeOnOff`) |
| 29 | Battery calibration stage 0–7 (0 off, 1 discharge, 2 set lower, 3 charge, 4 set upper, 5 balance, 6 set full capacity, 7 finish). Write only 0 (stop), 1 (start), 3 (charge only) |
| 52 | Power factor, raw/10000 − 1 |
| 55 | Battery capacity in Ah |
| 104 | Battery self-heating (doc "Reserved"); three-phase 101–104 are grid adjustments |
| 111 / 112 | Battery charge / discharge rate, C/100, max 50 |
| 114 | Battery cutoff % (doc `bDisMinSoc`) |
| 116 | Charge target; on 10-slot firmware charging stops at min(HR 116, HR 242) (#576) |
| 199 | Parallel mode (doc `ParaOutputMode`, 0–4, maybe not boolean) |
| 311 | Export priority: 0 Load First, 1 Battery First, 2 Grid First |
| 313 / 314 | Inverter charge / discharge power %, **1–100** (0 is rejected; GivTCP sends 1) |
| 317 | Enable EPS |
| 318 | Battery pause: 0 off, 1 charge, 2 discharge, 3 both |
| 319 / 320 | Pause start / end, HHMM, no swap. Setting a slot in the app also sets HR 318 = 3 |
| 331 | Force off grid (doc `GatewayOnOff`, 0–255) |
| 480–498 | The inverter's copy of its EMS settings (v4.1.6 doc): 480 EMS status, 481 battery power mode, 482 SOC adjust, 483/484 discharge time, 485 discharge enable, 486/487 charge time, 488 charge enable, 489 active power rate, 490 on/off, 491 SOC, 492 battery power, 493 load, 494 parallel enable, 497 inverter power, 498 fault word. Not exposed |
| 540–573 | Smart load / generator (Gateway 2 / AIO 2). Not exposed |
| 4102–4114 | Write-only seed registers, not live counters. **Remove from battery-total fallback** |
| 4141/4142 | Inverter export total ÷10 |

Single-phase input:

| IR | Meaning |
|---|---|
| 0 | Status: 0 waiting, 1 normal, 2 warning, 3 fault, 4 updating |
| 14 | Charge status: 0 idle, 2 charging, 3 finishing, 5 discharging |
| 16 | Inverter output power factor |
| 24 vs 30 | 24 is the inverter AC terminal, 30 the grid CT |
| 39 / 40 | Inverter fault / warning words (16-bit each; bit meanings unconfirmed, expose as hex) |
| 41, 55, 56 | Temperatures, **signed** ÷10 |
| 44–46 | PV generation on DC hybrids; inverter output on AC and AIO (PV registers on AC/AIO echo the AC side) |
| 57 | Battery warnings, LSB-first: 0 under-temp charge, 1 under-temp discharge, 2 over-temp charge, 3 over-temp discharge, 4 under-voltage, 5 over-voltage, 6 short-circuit, 7 over-current, 8 module temperature, 9 battery temperature, 10 BMS comms, 11 reserved, 12 soft-start, 13 voltage low, 14 voltage high, 15 meter comms |
| 13, 54 | Frequency; some units report ×10 (divide when > 100) |
| 180–183 | Battery totals alt (Gen1: total 180/181, today 182/183; read 0 on Gen2) |
| 247/248 | Combined generation power (32-bit) |

HR 223/224: 32-bit inverter fault word, MSB-first, named bits in the old GivTCP table (bit 11 is
"Hall Sensor").

Three-phase input: per-phase grid voltage/current IR 1061–1066, frequency 1067, inverter
power 1069/70, apparent power 1073/74, system mode 1075, status 1076, meter import/export
1079–1082, per-phase load 1083–1085 and inverter 1091–1093 (**signed W**, not ÷10), output
voltage 1094–1096, battery priority 1120 (0 load, 1 battery, 2 grid), battery type 1121, DC
status 1124, temperatures 1128–1130 (signed), battery voltage/SOC 1131–1135, battery power
1136–1139, battery current 1140 (**÷100**), EPS 1180–1192, faults 1300–1307 (LSB-first,
8 word tables), firmware 1325–1327 (numbers), energy 1360–1413 (uint32 ÷10). HR 1063 is
export power rate %÷10.

LV battery (slave 0x32+): temperatures IR 76–81, 103, 104 signed ÷10 (empty slot −273.0);
IR 95 battery current (trust only on Gen3/AC ARM ≥ 214 with BMS 3020–3999 or ≥ 4009);
IR 105/106 totals are stack-level, identical across packs (**don't sum**), wrap at 6553.5;
IR 107 force-discharge flag; capacities IR 84–89 ÷100 Ah; IR 91 high byte bit 1 charge
MOSFET, bit 2 discharge MOSFET. Battery types by serial prefix: BE/BJ 5.2 (102 Ah), AC 5.12
Gen3 (106 Ah), BG 8.2 (160 Ah), DZ 9.5 Gen3 (186 Ah).

HV BCU: IR 67/68 are counts, IR 70 status (0 init, 1 precharge, 2 standby, 3 charging,
4 discharging, 5 error, 6 updating, 7 off, 8 production), IR 103/105 are max (not min)
charge values, IR 114–119 warning/protection/fault words. HV modules: stack n, module k at
slave 0x50 + k, base IR 60 + 120 × n (the current code already does this).

Meter: apparent power IR 76–79 ÷10; power factor signed ÷10000.

## D. Quirks

- Charge slot 2 is HR 243/244 on 10-slot firmware; HR 31/32 writes error there.
- Gen1 ARM 451 doesn't answer reads of HR 313/314/318 but accepts HR 318 writes.
- Blocks that never answer: HR 540 on everything known; HR 300 on some AC firmware; IR 1000+
  errors on AIO / AIO-HY and zeros on HV Gen3.
- The dongle relays its own cloud polls (~every 306–312 s) to every client, sometimes with
  larger blocks; a covering block counts as fresh.
- Gen1 ARM 187 sometimes splices the IR 180 block into IR 0 registers 28–59; reject and re-read.
- Bad-read check: modbus_version > 2, modbus_address / user_code / heatsink > 100, or any of
  them unread.
- Today counters reset at slightly different times around midnight.
- Some dongles ignore requests sent immediately after connecting.
